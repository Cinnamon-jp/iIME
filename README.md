# iIME (Google Chrome 拡張機能)

ユーザーに「入力モードの切り替え」を意識させない、完全自動言語判別型の次世代ブラウザ専用IMEです。

## 概要

従来の文字入力では、日本語（かな）と英語（アルファベット）を切り替えるために、毎回 `半角/全角` キーや `Cmd + Space` などを押す必要がありました。

**iIME** は、ユーザーからの入力を常にダイレクトなキー入力（アルファベット等）として受け付け、文脈や入力パターン、内蔵された英単語辞書から**拡張機能側が自動で言語を判断・変換**します。これにより、モード切り替えのパラドックスから解放され、シームレスでストレスフリーなタイピング体験を実現します。

---

## 主な特徴

* **常時アルファベット受付:** 入力モードは1つだけ。常に英語を入力する感覚でタイピングを始められます。
* **ハイブリッド入力ロジック (自動言語判別):** 
  * `nihongo` と打てば、自動的に「日本語」にリアルタイム変換されます。
  * `apple` と打てば、内蔵辞書とのマッチングにより、英単語としてそのまま確定されます。
  * `korehaapple` のように日本語と英語を混ぜて一気にタイプしても、スペースキーを押すだけで「これはapple」とスマートに部分判別して確定します。
* **Google IME API との強力な連携:** 入力が一瞬止まった瞬間（80msのデバウンス）、バックグラウンドで高確率な漢字へ自動で事前置換。`Tab` キーを押すことで、Googleの豊富な変換候補を次々に切り替えることが可能です。
* **インテリジェントなスペース・Shift挙動:** 
  * `Shift` キーを押しながらタイピングすると、一時的な「英語モード」へ即座に突入。
  * 英語モード中のスペースキーは「英語の確定スイッチ」として機能し、余計な空白を挿入することなくスムーズに日本語入力へ復帰できます。

* **ビジュアルフィードバック:** モードが切りかった瞬間や確定時には、入力フォームがスタイリッシュに発光するエフェクト（`triggerGlow`）を搭載。視覚的にも気持ちの良いタイピングを実現します。

---

## 🛠 現在の技術スタック

* **フロントエンド:** JavaScript (Vanilla JS), CSS3
* **アーキテクチャ:** Google Chrome Extension (Manifest V3)
* **外部API:** Google Transliterate API (日本語かな漢字変換)
* **データ構造:** ローマ字・かな変換辞書 (`jpDictionary`), 軽量英単語探索用配列 (`englishWords`)

## 導入・使用方法（クイックスタート）

本プロジェクトは現在、開発者向けのChrome拡張機能として提供されています。リポジトリをダウンロードしてからブラウザで有効化するまでの手順は以下の通りです。

### 1. リポジトリのダウンロード

まずは、本リポジトリをご自身のローカル環境にダウンロードします。ターミナルを開き、任意のディレクトリで以下のコマンドを実行してください。

```bash
git clone [https://github.com/Cinnamon-jp/iIME.git](https://github.com/Cinnamon-jp/iIME.git)
```

(※ZIPファイルでダウンロードした場合は、任意の場所に解凍してください)

### 2. Google Chrome へのインストール

1. **拡張機能管理画面を開く**
   Google Chrome を開き、URLバーに `chrome://extensions/` と入力してエンターを押します。
2. **デベロッパーモードを有効化**
   画面右上にある**「デベロッパー モード」**のトグルスイッチを **ON** にします。
3. **パッケージ化されていない拡張機能を読み込む**
   画面左上に表示される**「パッケージ化されていない拡張機能を読み込む」**ボタンをクリックします。
4. **フォルダを選択**
   ファイル選択ダイアログが表示されるので、手順1でダウンロード（または解凍）した **`iIME` のルートフォルダ（`manifest.json` が入っているフォルダ）** を選択します。

これだけでインストールは完了です！拡張機能一覧に「iIME」が表示されていれば成功です。

### 3. 実際の使い方

1. 適当なウェブサイト（Google検索画面やメモ帳ツールなど）を開きます。
2. **OS標準のIME（Microsoft IMEやMacの日本語入力）を「半角英数」モードにします。**
3. 入力フォームにカーソルを合わせ、そのまま `sorehakininaru` や `this is apple` とタイピングしてみてください。
4. `Space` で確定、`Tab` で漢字候補の選択、`Backspace` でリセット、`Enter` で完全確定が行われます。
